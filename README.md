### 03 AnPPT — AI 生成 · 可编辑 PPT · 内测中

甲方、运营、技术、我，四个人四种语言。先理清 PPT 的底层逻辑：**版式是数据结构，不是画布**，再把它拆成可生成、可编辑的中间层。架构说不清楚时最贵的不是写代码，是反复返工——所以先画图、再做。

- **角色**：产品研发 · 体验判断 · 持续迭代
- **核心**：生成 → 可编辑的格式转换
- **流程**：一句话/一份文档 → 章节大纲 → 母版与占位 → 可编辑 PPTX 交付
- **现状**：内部在用 · 未公开
